An open passport spread for the Republic of Vessalia, a small island republic of lighthouses and ferry ports that does not exist. The program draws the whole document with PIL: a data page with a drawn portrait and ghost image, bilingual fields, an observation exempting the bearer — a keeper of lights — from harbour dues, and a machine-readable zone with genuine ICAO check digits; facing it, a visas page whose Kordavian visa sticker (fee paid, valid 10 Mar – 10 Apr 2023) and six border stamps tell one consistent travel history, every stamp dated after the passport's issue on 09 Jan 2023.

## Run it

```sh
python3 main.py
```

That writes the spread to `/output/entry.png` (1024×768 PNG). The program uses only Pillow and the standard library, and is deterministic: every run produces the same image.
